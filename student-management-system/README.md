# Student Management System

A command-line Student Management System developed using Python. This project allows users to manage student records through basic CRUD (Create, Read, Update, Delete) operations.

## Features

- **Add Student** – Add new student records with an ID, name, age, and course.
- **View Students** – Display all registered student records.
- **Search Student** – Find a student using their student ID.
- **Update Student** – Modify existing student information.
- **Delete Student** – Remove student records with confirmation.
- **JSON Data Storage** – Save and load student records using a JSON file.

## Technologies Used

- Python 3
- JSON
- File Handling

## How to Run

1. Make sure Python 3 is installed on your computer.
2. Clone this repository:

   ```bash
   git clone https://github.com/care-sey/project.git
   ```

3. Navigate to the project folder:

   ```bash
   cd project/student-management-system
   ```

4. Run the application:

   ```bash
   python main.py
   ```
